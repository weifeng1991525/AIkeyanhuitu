## 1. 项目概览

### 技术栈
| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | Next.js 14 (App Router) + Tailwind CSS | React全栈框架 |
| 后端 | Next.js API Routes + Prisma ORM | 前后端一体化 |
| 数据库 | PostgreSQL 14+ | 关系型数据库 |
| 认证 | WeChat OAuth + JWT (jose) | 微信扫码登录 |
| AI | OpenAI GPT-4 + DALL-E 3 | 假说生成 + 图片生成 |
| 状态管理 | Zustand | 轻量级状态管理 |
| 图表 | Recharts | 后台统计图表 |

### 项目结构
```
medai-pro/
├── src/app/              # 页面 + API路由（前后端一体）
│   ├── home/             # 首页
│   ├── hypothesis/       # 假说图生成
│   ├── roadmap/          # 技术路线图
│   ├── tools/            # 扩展工具
│   ├── auth/             # 登录/回调
│   ├── membership/       # 会员中心
│   ├── admin/            # 后台管理（6个子页面）
│   └── api/              # 12个API端点
├── src/components/       # 22个React组件
├── src/lib/              # 核心库（DB/Auth/AI/WeChat）
├── prisma/               # 数据库Schema + 种子数据
└── docs/                 # 文档
```

## 4. Step 1: 服务器环境搭建

### 4.1 SSH连接服务器

```bash
ssh root@你的服务器IP
```

### 4.2 安装Node.js 18

```bash
# 使用NodeSource安装
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证
node -v   # v18.x.x
npm -v    # 9.x.x
```

### 4.3 安装PostgreSQL

```bash
# 安装
sudo apt-get update
sudo apt-get install -y postgresql postgresql-contrib

# 启动并设置开机自启
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 创建数据库和用户
sudo -u postgres psql <<EOF
CREATE USER medai WITH PASSWORD '你的强密码';
CREATE DATABASE medai_pro OWNER medai;
GRANT ALL PRIVILEGES ON DATABASE medai_pro TO medai;
EOF
```

### 4.4 安装PM2（进程管理）

```bash
sudo npm install -g pm2
```

### 4.5 安装Nginx（反向代理）

```bash
sudo apt-get install -y nginx
sudo systemctl start nginx
sudo systemctl enable nginx
```

### 4.6 配置防火墙

```bash
sudo ufw allow 22    # SSH
sudo ufw allow 80    # HTTP
sudo ufw allow 443   # HTTPS
sudo ufw enable
```

## 6. Step 3: 微信开放平台配置

### 6.1 创建网站应用

1. 登录 [微信开放平台](https://open.weixin.qq.com/)
2. 管理中心 → 网站应用 → 创建网站应用
3. 填写应用信息：
   - **应用名称**: MedAI Pro 医学科研AI平台
   - **应用简介**: 基于AI的医学科研辅助工具
   - **应用官网**: https://你的域名.com
4. 提交审核（1-3个工作日）

### 6.2 配置授权回调域

审核通过后：
1. 进入应用详情 → 开发信息
2. **授权回调域** 填写: `你的域名.com`（不带https://）
3. 记录 **AppID** 和 **AppSecret**

### 6.3 前后端对接说明

微信扫码登录流程：
```
用户点击"微信登录" → 前端请求 /api/auth/wechat/login
→ 后端生成微信OAuth URL → 前端跳转到微信扫码页面
→ 用户扫码确认 → 微信回调 /api/auth/wechat/callback
→ 后端获取用户信息 → 创建/查找用户 → 签发JWT Cookie
→ 前端重定向到首页（已登录状态）
```

**关键文件：**
- `src/lib/wechat.ts` — 微信API封装
- `src/app/api/auth/wechat/login/route.ts` — 生成登录URL
- `src/app/api/auth/wechat/callback/route.ts` — 处理回调
- `src/components/auth/WeChatLogin.tsx` — 前端扫码组件

## 8. Step 5: 域名与HTTPS配置

### 8.1 域名解析

在你的域名服务商（阿里云/腾讯云DNS）添加A记录：
```
类型: A
主机记录: @ (或 www)
记录值: 你的服务器公网IP
TTL: 600
```

### 8.2 Nginx反向代理

```bash
sudo nano /etc/nginx/sites-available/medai-pro
```

填入以下内容：
```nginx
server {
    listen 80;
    server_name 你的域名.com www.你的域名.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }

    # 文件上传大小限制
    client_max_body_size 10M;
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/medai-pro /etc/nginx/sites-enabled/
sudo nginx -t          # 测试配置
sudo systemctl reload nginx
```

### 8.3 安装SSL证书（Let's Encrypt免费）

```bash
# 安装certbot
sudo apt-get install -y certbot python3-certbot-nginx

# 获取证书（自动修改Nginx配置）
sudo certbot --nginx -d 你的域名.com -d www.你的域名.com

# 自动续期（certbot已自动设置cron）
sudo certbot renew --dry-run
```

### 8.4 更新环境变量

```bash
nano /home/medai-pro/.env.local
# 确保 NEXTAUTH_URL 使用 https
NEXTAUTH_URL="https://你的域名.com"

# 重启服务
pm2 restart medai-pro
```

## 9. Step 6: 支付系统对接

### 9.1 推荐方案：微信支付（最低成本）

**前提条件：**
- 已有企业资质的微信支付商户号
- 已开通JSAPI支付/Native支付

**对接步骤：**

1. **注册微信支付商户号** → [微信支付商户平台](https://pay.weixin.qq.com/)
2. **关联微信开放平台应用** → 在商户平台绑定你的网站应用AppID
3. **安装SDK**:
   ```bash
   npm install wechatpay-node-v3
   ```
4. **创建支付路由** `src/app/api/payment/`:
   - `create/route.ts` — 创建支付订单（返回微信支付二维码URL）
   - `callback/route.ts` — 支付回调通知处理
   - `query/route.ts` — 查询支付状态

### 9.2 备选方案：模拟支付（开发测试阶段）

项目已内置模拟支付流程（`src/app/api/membership/subscribe/route.ts`），可直接使用：
- 用户选择会员方案 → 点击支付 → 模拟支付成功 → 自动开通会员
- **生产环境务必替换为真实支付接口**

### 9.3 支付流程图

```
用户选择方案 → POST /api/membership/subscribe
→ 创建Order记录(status: PENDING)
→ 调用微信支付API创建预支付订单
→ 返回支付二维码URL
→ 用户扫码支付
→ 微信回调 POST /api/payment/callback
→ 验签 + 更新Order(status: PAID)
→ 激活Membership + 增加额度
→ 返回success给微信
```

## 10. 前后端对接详解

### 10.1 整体架构

由于采用 Next.js 全栈方案，前后端在**同一个项目**中，API通过 Next.js API Routes 实现：

```
前端页面 (src/app/*/page.tsx)
    ↓ fetch/axios
API路由 (src/app/api/*/route.ts)
    ↓ Prisma ORM
PostgreSQL数据库
    ↓ HTTP请求
OpenAI API / 微信API
```

### 10.2 API端点清单

#### 认证相关
| 端点 | 方法 | 说明 | 认证 |
|------|------|------|------|
| `/api/auth/wechat/login` | GET | 获取微信登录URL | 否 |
| `/api/auth/wechat/callback` | GET | 微信回调处理 | 否 |
| `/api/auth/session` | GET | 获取当前会话 | Cookie |
| `/api/auth/session` | DELETE | 退出登录 | Cookie |

#### AI生成
| 端点 | 方法 | 说明 | 额度消耗 |
|------|------|------|----------|
| `/api/generate/hypothesis` | POST | 假说图生成 | 1次 |
| `/api/generate/roadmap` | POST | 技术路线图生成 | 1次 |
| `/api/generate/image` | POST | 通用图片生成 | 2次 |

#### 会员系统
| 端点 | 方法 | 说明 | 认证 |
|------|------|------|------|
| `/api/membership/plans` | GET | 获取会员方案 | 否 |
| `/api/membership/subscribe` | POST | 订阅/充值 | 是 |
| `/api/membership/orders` | GET | 查询订单 | 是 |

#### 后台管理（需ADMIN角色）
| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/admin/prompts` | GET/POST/PUT/DELETE | 提示词CRUD |
| `/api/admin/skills` | GET/POST/PUT/DELETE | Skill CRUD |
| `/api/admin/analytics` | GET | 统计分析数据 |
| `/api/admin/users` | GET/PUT | 用户管理 |
| `/api/upload` | POST | 文件上传 |

### 10.3 前端调用API示例

```typescript
// 假说生成 - 前端调用示例
// 文件: src/app/hypothesis/page.tsx

const handleSubmit = async (data: HypothesisFormData) => {
  setIsLoading(true);
  try {
    const res = await fetch('/api/generate/hypothesis', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data),
    });
    const result = await res.json();
    if (result.success) {
      setResult(result);  // 显示生成结果
    } else {
      toast.error(result.message);  // 显示错误
    }
  } catch (err) {
    toast.error('网络错误，请重试');
  } finally {
    setIsLoading(false);
  }
};
```

### 10.6 后台管理对接

后台管理系统路径: `/admin`

**访问方式：**
1. 使用管理员账号微信登录
2. 或直接访问 `/admin`（系统自动校验ADMIN角色）

**管理功能：**
- **提示词管理** (`/admin/prompts`): 编辑AI系统提示词，控制生成质量
- **Skill管理** (`/admin/skills`): 组合多个提示词为复合技能
- **统计分析** (`/admin/analytics`): 用户活跃度、生成次数、收入趋势
- **会员管理** (`/admin/users`): 查看/封禁用户，手动调整额度
- **充值订单** (`/admin/orders`): 查看所有支付记录

## 11. 常见问题排查

### Q1: 微信扫码后回调失败
```bash
# 检查回调URL配置
# 微信开放平台 → 应用详情 → 授权回调域
# 必须是纯域名，不带路径和协议
# 正确: yourdomain.com
# 错误: https://yourdomain.com/callback
```

### Q2: 数据库连接失败
```bash
# 检查PostgreSQL状态
sudo systemctl status postgresql

# 检查连接
psql -U medai -d medai_pro -h localhost

# 检查.env.local中的DATABASE_URL格式
# 正确格式: postgresql://用户名:密码@localhost:5432/数据库名
```

### Q3: OpenAI API超时
```bash
# 如果使用国内转发渠道，修改 src/lib/ai.ts
const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
  baseURL: 'https://你的转发地址/v1',  // 添加这一行
});
```

### Q4: 端口被占用
```bash
# 查看3000端口占用
lsof -i :3000
# 或
netstat -tlnp | grep 3000

# 杀死占用进程
kill -9 进程ID
```

### Q5: PM2服务异常
```bash
pm2 logs medai-pro --lines 100   # 查看日志
pm2 restart medai-pro             # 重启
pm2 monit                         # 实时监控
```

### Q6: Nginx 502 Bad Gateway
```bash
# 检查Next.js是否在运行
curl http://localhost:3000

# 检查Nginx配置
sudo nginx -t

# 检查Nginx错误日志
sudo tail -f /var/log/nginx/error.log
```
